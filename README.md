## 音效

音效和背景音乐分别由右上角两个开关控制，默认均为开启。首次点击、触摸或按键后解锁浏览器声音。音效音量60%，背景音乐为用户提供的《My Curse, My Fate》，音量40%，整首循环播放。两种声音独立控制，音乐关闭后再开会从原位置继续；切换到后台暂停音乐，返回时恢复。游戏暂停不重置音乐。视频主体音频按停顿切为九段，按等级顺序映射：投放播放该果子的音效，合成播放新等级音效；后一个覆盖前一个，避免连锁合成叠音。暂停、重开及关闭音效会停止当前短音效，背景音乐由自己的开关独立控制。已去掉约11.1秒之后的平台片尾内容。

使用原视频声音，不做变调。音频片段起点和时长（秒）：0.10/1.12，1.34/0.96，2.38/0.80，3.22/0.67，3.91/0.45，4.35/0.64，5.02/1.25，6.49/1.57，8.48/2.62。

## 难度校准

保持原版重力、滚动、投放速度、1.75秒超线判负规则。以下记录来自此前480×620游戏框；当前加高至700，并限制随机最高只出小罗宾，未重新估算通关率。三种简单策略各运行150局，随机策略0次、优先同级策略5次、分区策略2次，共450局7次合成最终果（约1.6%）；原七级同类模拟为450局2次。两版均属于低通关率，九级单局平均约20–24次投放，比原版17–18次稍长。模拟不代表真人通关率，实际难度随操作策略变化。

素材使用用户提供的图像；新增两张按原图画风处理头部和泡泡，没有沿用此前添加头发/装饰的重绘版本。
